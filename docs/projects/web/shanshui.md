## 项目缘起

「山水之间」是我的个人博客。我用它整理 AI、Agent、检索增强生成与开发实践中的笔记，记录项目的实现过程，也保留学习中值得回顾的问题与想法。

首页提供近期内容的浏览入口，文章页负责长期整理，项目页记录具体实践。随着内容积累，读者可以按时间阅读，也可以从标签进入感兴趣的主题。

## 主要功能

### 文章阅读与整理

文章索引按年份分组，支持标签筛选和分批加载。每篇文章展示发布日期、标签与预计阅读时间；正文提供章节目录、阅读进度及相关内容入口。

技术笔记支持代码高亮、行号、复制按钮、Mermaid 图表和数学公式。正文图片可以点击放大，适合查看流程图和界面截图。

### 项目展示

项目有独立的介绍页，用于说明背景、功能、实现方法和使用方式。项目索引可以切换画廊与列表视图；有外部地址时，提供“访问项目”入口，优先打开演示地址，其次打开源码仓库。

### 双语访问

网站提供中文与英文界面。已有译文的内容可以直接切换，尚未翻译的文章会展示提示，并提供中文原文入口。英文内容独立维护。

## 设计与实现

<span id="素纸淡墨的视觉"></span>

### 从浅青绿过渡到白色

首页顶部使用浅青绿色渐变，向下逐渐淡化为白色。正文区域保持浅色背景与深色文字，阅读时减少背景对内容的干扰。

文章与项目保留长卡片形式。宽屏最多并排展示三张卡片，中间卡片以深色背景突出，左右卡片略小；窄屏展示单张卡片。卡片集中呈现标题、简介和标签，帮助读者判断内容是否值得继续阅读。

### 克制的动态

轮播由读者主动操作，支持卡片两侧的按钮、拖动和键盘切换。切换时保留位移、缩放与颜色过渡，底部以固定长度的位置条和数字显示当前位置。

轮播区域获得键盘焦点后，可用左右方向键切换，Home 和 End 跳到首尾。只有一个项目时直接展示卡片，隐藏切换控件。系统开启“减少动态效果”时会简化动画，并保留操作功能。

### 内容与页面分离

文章和项目使用 Markdown 维护，标题、简介、日期与标签写在文件开头。首页和索引从这些内容中自动生成，新增文章无需逐处修改页面。

Vue 3 与 TypeScript 负责页面组件，VitePress 构建静态页面。GitHub Actions 在发布前执行类型检查、构建和站内链接检查，再将结果部署到 GitHub Pages。

```text
Markdown → VitePress 构建 → 链接检查 → GitHub Pages
```

## 本地使用

安装 Node.js 22 或更新版本，克隆页面顶部链接的仓库，在项目目录依次运行以下命令。

<template #step-1>

```bash

```

</template>
<template #step-2>

```bash
npm run dev
```

</template>
</CodeSteps>

打开终端显示的地址即可预览。Windows 也可以双击仓库里的 `preview.cmd` 启动开发预览。

发布前运行：

```bash
npm run check
npm run build
```

文章放在 `docs/journal/`，项目介绍放在 `docs/projects/`，图片放在 `docs/public/images/`。仓库的 `templates/` 提供文章与项目模板；完整的目录说明、字段解释和部署步骤见 [项目 README](https://github.com/smwy-cj/smwy-cj.github.io/blob/main/README.md)。
