## 项目缘起

个人网站既是介绍自己的入口，也可以是一份持续生长的学习档案。这份示例以当前网站为背景，展示项目详情应该如何组织。

目标是让来访者能够快速认识网站主人、找到感兴趣的项目，并顺畅阅读相关技术笔记。

## 设计与实现

### 素纸淡墨的视觉

以暖白与炭灰建立阅读层次，用低饱和灰绿作为辅助。山水图形采用 SVG 绘制，与页面背景自然相融。

### 克制的动态

- 鼠标移动时，远山与近山以不同幅度轻移。
- 卡片根据指针位置产生微小倾斜。
- 点击出现一圈淡淡的涟漪。
- 页面滚动时，新的内容逐段显现。
- 尊重系统的减少动态效果设置，也提供手动关闭开关。

### 内容与页面分离

项目和文章使用 Markdown 编写，个人信息集中在配置文件中维护。构建时扫描内容，生成分类列表与搜索数据。

```text
Markdown 内容 → 静态页面 → GitHub Actions → GitHub Pages
```
