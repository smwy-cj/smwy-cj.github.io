## 动态的目的

动态可以告诉使用者：这里可以操作、操作已经发生、页面正在变化。幅度和频率都应与内容的优先级相匹配。

## 鼠标移动

多层山水以不同速度移动，可以建立轻微的空间感。使用 requestAnimationFrame 合并指针更新，避免每次事件都触发页面布局。

卡片倾斜的幅度应足够小，不影响文字辨认，也不改变点击目标。

## 滚动与显现

内容进入可视范围时再逐段显现，能帮助阅读者理解章节顺序。使用 IntersectionObserver 观察区块，显现后停止观察。

即使脚本未执行，正文也应该可见。不要让动画成为阅读内容的前提。

## 点击反馈

淡淡的涟漪可以确认点击位置，但实际按钮也需要焦点状态、文字和清楚的操作结果。

## 减少动态效果

尊重系统偏好，并允许手动关闭。

```css
@media (prefers-reduced-motion: reduce) {
  .landscape {
    animation: none;
    transform: none;
  }
}
```

最终仍要在手机与键盘操作中检查体验，确保动态不会阻碍内容。
